Sources and method

OpenWeather’s five-day API supplies three-hourly forecasts. The independent NOAA Global Forecast System series uses a fixed model run delivered by Open-Meteo. The archive saves future valid hours on a six-hour schedule. Lead time starts at capture. A model initialization time identifies the run. Neither feed supplies a public release timestamp for these receipts.

Hourly station temperatures come from Environment and Climate Change Canada’s MSC GeoMet. A pair requires the same station and exact valid UTC hour with an unflagged temperature. A positive error means the forecast was warmer. An absent reading can arrive later. Missing observations remain blank.

Time-of-day bins use local civil time from midnight, 06:00, noon and 18:00. Revisions compare consecutive saved forecasts from the selected source for a single valid hour. The filters apply to the newer forecast. Forecast accuracy and revisions describe only these two stations and archived captures.
